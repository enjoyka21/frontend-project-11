# RSS агрегатор

[![hexlet-check](https://github.com/enjoyka21/frontend-project-11/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/enjoyka21/frontend-project-11/actions)
[![CI](https://github.com/enjoyka21/frontend-project-11/actions/workflows/ci.yml/badge.svg)](https://github.com/enjoyka21/frontend-project-11/actions)

Учебный проект Хекслета по разработке RSS-агрегатора.

## Стек

- JavaScript
- Vite
- Tailwind CSS
- ESLint

## Установка

```bash
git clone https://github.com/enjoyka21/frontend-project-11.git
cd frontend-project-11
make install
```

## Использование

Запуск проекта:

```bash
npm run dev
```

Сборка:

```bash
npm run build
```

Проверка кода:

```bash
npm run lint
```

## Автоматические проверки

При каждом push на GitHub запускаются автоматические проверки:

- Hexlet Check
- ESLint
- Сборка проекта

Конфигурация находится в `.github/workflows/`.

**Важно:** не удаляйте и не переименовывайте файл `hexlet-check.yml`.
